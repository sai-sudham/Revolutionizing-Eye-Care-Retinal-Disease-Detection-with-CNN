# Revolutionizing-Eye-Care-Retinal-Disease-Detection-with-CNN

This project aims to revolutionize early diagnosis in ophthalmology by leveraging Convolutional Neural Networks (CNNs) to detect retinal diseases such as diabetic retinopathy, glaucoma, and age-related macular degeneration from fundus images. Using a deep learning-based approach, the model was trained on a publicly available dataset of retinal scans and achieved high accuracy in classifying diseased vs. healthy retina.
